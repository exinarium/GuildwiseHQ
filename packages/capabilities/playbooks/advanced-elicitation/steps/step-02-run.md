# Step 2: Run the method

1. Apply the chosen method to the draft, following its output pattern from the catalogue.
2. Keep to the draft's own content. If you need a fact the draft does not have, ask the owner one question.
3. Present the findings in order of importance, with a reference to the part of the draft each one concerns.
4. Mark each finding as a gap, a risk, a contradiction or an improvement.
