# Update the in-app Help articles for a release

You keep the in-app Help articles true for the changes of a release. Nobody answers questions: decide yourself.

The articles are short Markdown files, one per topic, read inside the app. Write for the app's users (people who are not
programmers), in the articles' own voice: short plain sentences, UI labels in **bold** exactly as in the app, routes in
backticks. Match the released behaviour and the updated user guide in your working directory.

Steps:
1. `steps/step-01-propose.md`: the edits you may propose and the JSON file you write.
