# Step 6: Hand-off

1. Present the finished PRD and ask the owner to approve it. Move the document to review.
2. After approval the document is published to the vault and can start a business analyst intake.
3. Offer to list the features that would become cards, with a suggested order, so the owner can see the shape of the work.
4. Do not create cards yourself. The intake does that, linked to this document.
