# Step 1: Gather

1. Load the inputs: the brief, the discovery notes, the minutes. Summarise them in five lines and confirm.
2. List contradictions between the inputs and ask the owner to resolve each one.
3. List the decisions already made and the open questions that remain.
4. Create the document from `assets/prd-template.md` and fill the header (title, owner, date, status, source sessions).
