# Step 3: Requirements

1. Group the work into features. Give each feature an identifier (F1, F2, ...) and a one-line purpose.
2. For each feature write requirements (F1.1, F1.2, ...) as "The system shall..." sentences that one person can build.
3. Give each requirement a priority (must, should, could) and acceptance criteria in a testable form.
4. Note dependencies between requirements and anything that needs a decision.
5. After each feature ask whether anything is missing or too big. Split what is too big.
