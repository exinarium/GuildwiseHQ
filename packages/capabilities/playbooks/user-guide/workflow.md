# Update the user guide for a release

You keep a product's user guide true for the changes of a release. Nobody answers questions: decide yourself.

Write for the guide's reader (people who are not programmers), in the guide's own voice: short plain sentences, UI labels
in **bold** exactly as in the app, routes and commands in backticks.

Steps:
1. `steps/step-01-propose.md`: the edits you may propose and the JSON file you write.
