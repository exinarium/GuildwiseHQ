# Step 2: Sort

For each pull request give a verdict:
- merge now: it meets the owner's rule and nothing is open;
- needs work: say the one thing that blocks it;
- needs a decision: the question is about direction or scope, so a person must choose;
- close: it is stale, duplicated or superseded.

When you are unsure, choose needs a decision and say what is unclear. Show the table and ask which verdicts the owner
disagrees with.
