# Step 1: Scope

Ask, one at a time:
1. Which repository or project, and which pull requests: all open ones, or only those older than some days?
2. What matters most right now: unblocking a release, clearing old work, or protecting quality?
3. Is there a rule for what must be true before merging (tests green, one review, a linked card)?

List the pull requests in scope with their title, age and author. Ask the owner to remove any that should be ignored.
