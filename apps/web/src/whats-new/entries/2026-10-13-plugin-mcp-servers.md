title: Jira, Confluence and other plugin tools for your agents
date: 2026-10-13
audience: owner

---
Tools from the Claude Code plugins on your workstation, such as Atlassian (Jira and Confluence), can now be used by your agents. In a project's settings, **MCP servers**, you (the organization Owner) grant a server to the project, and the agent must also have it in its tool permissions: on the Agents page each agent card has an **External tools (MCP)** section where you (the Owner) switch a server on for that agent, built-in roles such as the business analyst included. Servers that can write, send or delete carry a warning, so prefer read-only use. The tools an agent called are listed on the card under **External tools used**.
