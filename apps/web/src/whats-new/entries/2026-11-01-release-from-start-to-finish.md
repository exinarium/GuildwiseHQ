Approving a release now prepares it for you: the changelog moves under the new version, version numbers go up and the release commit is pushed. Once it is merged, Guildwise tags it and creates the release page on GitHub or GitLab. If a step fails you get a clear message and **Retry** carries on from that step, without doing anything twice.
