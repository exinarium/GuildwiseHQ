---
title: Commits are made as you
date: 2026-10-14
audience: owner
help: /help/projects#commit-as
---
Every commit and merge made for a project now carries your own name and e-mail, never an agent's or the product's. Set it under **Commit as** in the project settings, or leave it empty to use the repository's git setting and then your workstation's. Commit messages and pull requests no longer mention cards, agents or Guildwise, and updates to tickets are refused if they do. If no identity is set anywhere, nothing is committed and the desk says where to set it.
