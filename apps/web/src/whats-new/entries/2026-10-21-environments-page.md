date: 2026-10-21

Every project now has an **Environments** page: how to start your app, the test site, the live site, any extra site, and the computers and servers they run on, each listed once. Add as many as you need, remove any of them (the running app is never touched), and let DevOps look first: its questions are real fields you can answer. Apps that run directly on a machine (a service, pm2) work as well as Docker apps.

**Deploys** is now **Releases**: what waits for you, what is live on every site, the history and the rules. Everyone can look; the Owner or an Admin releases, and can go back to an earlier version.
