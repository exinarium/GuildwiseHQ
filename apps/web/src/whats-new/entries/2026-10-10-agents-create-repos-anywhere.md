---
title: Agents can start repositories on any git host
date: 2026-10-10
audience: admin
help: /help/devops-and-hygiene#new-repository
---
When an agent needs a new repository, it can now ask for one on GitHub, GitLab, Azure DevOps or Bitbucket Cloud. You still approve it on the desk. The DevOps engineer can also help connect a workstation to a git host, without ever asking for your password or token.
