date: 2026-10-14
audience: all

Starting a branch again now replays the saved plan in seconds, with no DevOps run; if it fails, the DevOps engineer repairs it. The panel has **Restart** and **Update & restart** (fast-forward to the branch head), a stopped environment can be restarted for a day, and the services run in the runner's sandbox and keep running when the runner updates itself.
