---
title: Unstick an agent, and a working branch that keeps up
date: 2026-10-14
audience: owner
---
A shift that hangs can now be freed from the card, the Agents page or the Workstations page: stop the running command, or stop the shift and either re-queue the card or keep it with the same agent. A shift that has gone quiet is also stopped by itself after a while. The local working branch of each repository now follows origin when it is safe, and shows "N behind origin" with a Sync now button when it is not.
