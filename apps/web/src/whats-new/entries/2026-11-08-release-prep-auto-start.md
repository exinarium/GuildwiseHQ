---
title: Release prep can start by itself
date: 2026-11-08
audience: admin
help: /help/phases#release-prep
release: 1.6.0
---
Turn on **Start automatically when the release is ready on the test site** in the release prep settings, and prep begins as soon as the release is live and healthy on the test site and meets what the live site needs before it goes out (release hours and freeze do not count). The **Release prep** tab shows whether the release is ready, why not if it is not, and whether a run was started automatically or by whom.
