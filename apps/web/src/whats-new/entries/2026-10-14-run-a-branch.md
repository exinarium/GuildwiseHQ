---
title: Run a branch to try it
date: 2026-10-14
audience: all
help: /help/board-and-cards#run-a-branch
---
Press **Run this branch** on a card, or **Run branch...** on the board, and the workstation's DevOps engineer starts the project on that branch so you can try it. You see each service, its links and ports, the commit it runs, a live log, and **Stop** and **Extend**. It stops by itself after a few hours. Project settings has a new **Run and test** section for run instructions and services.
