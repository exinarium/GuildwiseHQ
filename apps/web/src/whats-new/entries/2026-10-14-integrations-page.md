date: 2026-10-14
audience: owner

The new **Integrations** page shows every login on a workstation in one place and lets you connect it from the browser: Claude (a subscription sign-in or an API key), GitHub, GitLab, Bitbucket Cloud, Azure DevOps, Jira and plugin MCP servers. Tokens are encrypted in your browser for that workstation, so the server never sees them. Notices such as "Claude login expired" now link straight to the right tile. Needs a runner with web connect; older runners show their state read-only with the terminal command.
