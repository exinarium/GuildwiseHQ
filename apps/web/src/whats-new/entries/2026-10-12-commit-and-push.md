title: Commit and push to the working branch, no pull request
date: 2026-10-12
audience: admin

---
Each repository in a project now shows two branches: the **main branch**, where pull requests go, and the **working branch**, where finished card work is combined (they can be the same). **How finished work lands** says what it does: **Commit and push to the working branch (no pull request)**, or **Pull request I approve**; cards in expert mode can also **push the card branch only**. A working branch that does not exist is created from the main branch and pushed, and the repository settings tell you when. When the two differ, **Open pull request** in the repository row opens one from the working branch to the main branch.
