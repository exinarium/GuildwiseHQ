date: 2026-10-15

---
Run a branch now finds a `BUILD.md` kept in the folder above your repositories (or the one you name in Run and test), fetches submodules, and checks the environment's own settings before it says something is missing. A failed environment stays on the board with its reason, **Try again** and **Dismiss**, and when the DevOps engineer needs an answer from you it shows **Waiting for you**.
