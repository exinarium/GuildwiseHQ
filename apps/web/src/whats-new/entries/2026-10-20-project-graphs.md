title: A brain for your project
date: 2026-10-20
audience: all

Every project now has a **code map**: a map of its code and docs, built on your own workstation and kept in the project vault. Agents use it to answer "where is this, and what touches it?" without reading many files, which aims to spend fewer tokens. We measure it honestly: one card in five runs without the map for four weeks, and the Costs page claims a saving only when the numbers support one. Nothing from your code is sent to Guildwise HQ.
