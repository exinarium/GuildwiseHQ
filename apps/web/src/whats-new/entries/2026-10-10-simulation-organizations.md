title: Simulation organizations for tests and demos
date: 2026-10-10
audience: superadmin
help: /help/simulation
---
You can now create an organization as a simulation, or switch an existing one over. Its agents run on a simulated workstation hosted by Guildwise, so nothing real is built and nothing is billed, and you can delete the whole organization and its data afterwards so the same email address can be used again.
