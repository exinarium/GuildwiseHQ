date: 2026-10-12

When adding a repository to a project, you can now set the **Project path**: the folder where your app lives if the code is in a sub-directory (a monorepo like `src/app`). The development environment check, package installs, and agents' build and test commands all run from that folder. Change the path later in the project's repository settings.
