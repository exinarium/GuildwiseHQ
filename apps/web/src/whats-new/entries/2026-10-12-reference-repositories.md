---
title: Reference repositories, and chats that can see your code
date: 2026-10-12
audience: all
help: /help/projects#reference-repos
---
In a project's settings the owner can now pick **Reference repositories**: other repositories the project's agents may read, in card work and in chats, so they can compare code. They get them read-only, secret files such as `.env` stay blocked, and every other repository stays blocked. A chat about a project (or a card that has not been started on that workstation) now sees the project's own repositories too, and agents are told which folders they can read.
