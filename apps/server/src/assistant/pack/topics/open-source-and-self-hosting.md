### Open source and self-hosting
Guildwise HQ is free and open source (Apache 2.0). Where the code is, what self-hosting needs, how to ask for a feature and how to help.
- The license: Guildwise HQ is licensed under Apache 2.0: any use, commercial use included, with no fee and no permission needed, so a company can use it without paying. Every feature is in the free version.
- Where the code is: The source is at github.com/exinarium/GuildwiseHQ, created by Pieter Jordaan. Questions and ideas go in GitHub Discussions, bugs in GitHub Issues, and contributions follow CONTRIBUTING.md in the repository.
- Feature requests: Anyone can suggest a feature: post it in GitHub Discussions under Ideas, or open an issue with the feature request template. Say what you are trying to do, not only what you want built.
- Self-hosting: Run it with Docker Compose (the app, Postgres and a Caddy proxy) on your own server with a domain name, an SMTP relay for invitation emails and ports 80 and 443 open. The guide is docs/DEPLOY.md in the repository. Agents still run on your own workstations.
- What self-hosting does not include: Hosting, backups, updates and support are yours to run when you self-host. Help with custom workflows, custom agent development and organizational planning is quoted on request: use Contact us where a hosted service offers it.
- Supporting the project: Optional ways to say thanks: star the repository, GitHub Sponsors, Ko-fi (ko-fi.com/exinarium), or the voluntary commercial license that the hosted site sells. The commercial license is optional because Apache 2.0 already allows commercial use.
