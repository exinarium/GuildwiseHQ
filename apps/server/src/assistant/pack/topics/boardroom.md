### Boardroom
Put a question to personas and agents, run by a Chair. Interject, keep a whiteboard, and turn the minutes into a PRD.
- Start a boardroom: Sidebar, Boardroom, New boardroom (any member).
- How a session runs: Round 1 is independent: each seat answers from your topic and brief alone, then all are revealed.
- Talk to the room: Type in the box at the bottom at any time. @name (or @all) calls on a seat: one that has not spoken in this round speaks next. Pause stops anything new from starting.
- The whiteboard: Sticky notes in five columns (Ideas, Risks, Questions, Decisions, Parked). Seats add notes; you can add, edit, drag, vote +1, merge and delete. In option scoring, a table shows each seat's 1 to 5 score per option and the totals; it is in the minutes too.
- Cost and time limits: The meter shows the cost so far and the estimate for the next round. With a cost limit, no new turn starts once it is used up; raise it or end the session. If it runs out before the Chair can write the minutes, you choose: Write minutes without the Chair's summary, or Raise the limit.
- Minutes and the PRD: When the session ends, or on Write minutes now, the Chair writes the minutes (positions, agreements, open disagreements, decisions, whiteboard) into Documents.
