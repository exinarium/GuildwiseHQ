### Capabilities and packs
The skills, personas and playbooks agents can use, how to add and approve a pack, write your own, and hire or chat with a persona.
- The registry: It lists every skill, persona and playbook and where it comes from: built in, your vault, a project or a pack. Pick a role's skills on Roles and workflows.
- Packs: Add a pack by git URL and tag (any repository of skills in the Agent Skills format, folders with a SKILL.md, works). It starts untrusted: nothing of it is used. Review and approve shows its files, scripts flagged, and approves that exact commit.…
- Project skills: Project skills lists the skills and personas found in project repositories (repository, path, hash). Nothing found there is used until an Owner or Admin has read it and marked it reviewed; a file that changes needs a new review. You also get a notice on your desk when something waits.…
- My capabilities: Write skills, personas and playbooks in the editor; the page checks them as you type. Each pack you write is stored on your workstation in the standard pack layout, so Export as zip gives a folder you can push to git unchanged.…
- Private repositories and workstations: For a private git repository add a deploy key (ssh) or token (https). Your browser encrypts it for each workstation you choose, which stores it for that pack only. A member's workstation asks its owner first (a request on their desk) and clones only after they accept.
- Hire from a pack: Members can hire too, for projects they are on and on their own workstation. Owners and Admins can also read the text of an organization pack before approving it, with a diff against the version approved before (the text is encrypted for your browser only).
- Chat with a persona: Chat on a persona opens a one-to-one chat on your own workstation. It only reads, and its cost is tracked. You can set a cost limit and a time limit for the chat; chats are deleted after 90 days. A private persona is only yours.
- Playbooks and the / menu: Type / in a chat or session box to list the playbooks and skills you may use (private packs only to you). Text after the command (/brainstorm pricing for teams) is the input of the playbook. A skill adds an instruction;…
