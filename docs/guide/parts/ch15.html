Agent Org Manager is a monorepo with workspaces for shared contracts, the server, the web app, the runner, and tests.

pnpm scripts (run from root)
pnpm dev—Start server and web locally (server :4600, web :5173)
pnpm test—Run all unit and integration tests
pnpm e2e—Run end-to-end Playwright tests
pnpm typecheck—TypeScript type check (strict)
pnpm lint—Biome linter and formatter
pnpm db:migrate—Apply SQL migrations to the aom DB
pnpm --filter @aom/server projections:rebuild—Replay all events to rebuild the projections (stop the server first)
pnpm --filter @aom/server admin:create—Bootstrap first admin account
pnpm build, pnpm e2e:prod, pnpm runner:dev—Build all bundles; scripted production compose check; run the runner against .dev/runner
pnpm package:runner—Build and package the runner tarball
