# Announcement: reinstall your runner (Guildwise 1.10.0)

A mail text for the operator of a Guildwise server to send to its users when runners must be reinstalled. That is the case
on any server with **Only signed runners** turned on (Platform > Security > Security settings), which is always the case on
Guildwise Cloud. On a self-hosted server with the setting off (the default), runners update themselves and you do not need
to send this. Guildwise Cloud's own version, for the users the owner re-invites, is in the guildwise-cloud repository
(`docs/announcements/1.10.0-runner-reinstall.md`).

Replace `<server address>` with your public address before you send it.

---

**Subject:** Reinstall the Guildwise runner on your computers

Hello,

Our Guildwise server now accepts only signed workstation runners (Guildwise 1.10.0). Runners installed before that are
refused, and they cannot update themselves into a trusted one. Your workstation shows **Reinstall required** until you
reinstall.

On each computer that runs Guildwise agents:

1. Sign in at `<server address>` and open **Workstations > Add a workstation**.
2. Copy the one-line command for your system and run it on that computer.
3. Answer the installer's questions about what the runner may do on this machine (**Setting local permissions**). The
   safe answer is the default.

Remove nothing by hand. The installer finds the old runner, stops it and moves its files into a quarantine folder
(`~/.guildwise-quarantine/`), and it reuses nothing from it. Never copy files from the old runner into the new one. You
can delete the quarantine folder once the new runner works.

If you ever gave the old runner sudo (administrator rights), change your computer password now: the old runner's
sealed sudo password may be known.

New in 1.10.0: privileged steps such as deploys, DevOps tasks and sudo now wait for a yes on your computer
(`guildwise-runner approve`), so nobody can run commands on your machine from the server.

Thank you.
